# 半成品个人工作台

**当前版本：v0.7.0（本地迭代） · Work in progress / 半成品。**

这是一个仍在本地迭代的个人成长与业务工作台，用于连接今日任务、项目进度、知识与 Skill、作品、想法、公开资讯和复盘。当前不作为成熟产品或生产服务。

## v0.7 可视化与记录保护

增加业务、项目、选题、知识与复盘的可点击图解，以及选题和对标卡片。参考网页截图只保存在本机，不随源码备份；其他机器打开时会提示截图暂不可用。

本机记录写入增加版本冲突检查：多个窗口同时编辑时，未合并的内容另存为本机恢复副本。文件或缓存的关键结构异常时停止静默覆盖；发布记录不再自动补写日期。已有记录的发布日期需与原平台核对。

朋友体验版使用独立示例数据，记录只存在访客自己的浏览器；不连接个人数据、实时搜索或 AI 接口。它用于分享界面体验，不能代替个人资料的异地备份。

## v0.6联网与AI研究

本地研究页可输入公开关键词，明确点击“只找参考”或“联网并AI研究”。Tavily key只从已有用户环境TAVILY_API_KEY读取；文字通过原本机relay。只发关键词与搜索标题/摘要，不附本机资料。结果附真实来源，提供内容对标建议、选题和本地任务。最近研究只读恢复不重复计费；失败不自动追加模型尝试。

真实验收仅搜索1次＋文字1次，返回6来源/2内容对标建议/3选题，未截断。缓存截断空白边界已修并验证重启恢复。无新增依赖或公网更新。数据在preview/local-data/web-research，独立保存，尚不包含在旧“备份任务与备注”导出中；需单独备份该目录。

## 当前功能

- 八个工作板块与清晰的说明、备注入口。
- 日期任务、昨天未完成带入/删除，日/周/月独立复盘与最近7次回看，下一步可安排明天；时间按America/Los_Angeles计算。
- 选题卡承接作品、想法、公开资讯、试用和AI结果，记录问题/操作/结果/验收、三个平台状态与链接；首页按不同卡片统计本周已发。
- 首页聚焦今天、本周内容、最多3个进行项目、1条资讯＋1个工具；整体节奏不强加到每个平台。
- 方法与案例卡支持输入、步骤、检查、来源及小行动，私人提炼数据仍留在本机。
- 本地项目、作品、Skill 和知识入口目录；文件与视频按受控ID预览。
- 固定官方公开资讯源手动刷新，显示来源、日期、失败和旧缓存。
- 本机文件保存、浏览器恢复副本和手动记录备份。
- AI工作区支持手动文字与生图，由本机服务按供应商和能力分别连接，主用明确失败时一次备用，显示使用线路和实际图片尺寸。
- 资讯卡可手动“让AI解释”：服务端只取公开缓存的标题、来源、日期、摘要、链接，结果能保存为选题、今日任务或想法；不自带联网搜索。
- 只发送手动输入，不自动读取私人资料作为模型上下文；密钥从Git忽略的本机私有配置读取，不进入浏览器。

## 本地启动

使用已有 Node.js 24+；公开 RSS/Atom 解析另需已安装的 Python 3。

```powershell
node preview/server.cjs
```

打开 http://localhost:8869 。Windows 启动辅助脚本中的 Node 路径按实际安装位置调整；可用 WORKBENCH_PYTHON 指向已有 Python。无需部署或安装新的 npm 依赖。

Windows快捷启动优先用已安装的Edge应用窗口打开，不修改系统默认浏览器；没有Edge才沿用默认浏览器。启动入口会等待最多30秒；失败或仍运行旧版本时显示系统提示。服务先监听再在后台线程整理资料，加载期间页面有明确状态和有界重试。

## 备份范围

本仓库保存源码、测试与脱敏设计文档；**不包含私人聊天索引、用户上下文、知识库正文、素材原件、运行记录、密钥或账号登录态**。

本机资料与记录位于 preview/local-data/，公开资讯缓存位于 preview/public-cache/，均不入库。源码版本不能替代这些数据的独立备份。新电脑需要另行恢复经筛选的本地资料，否则资料目录会为空。

AI配置放在Git忽略的 `.secrets/api-connections.private.v2.ini`；应用源码不包含凭据。新环境可参考[无密钥示例](docs/frontend/AI-CONNECTIONS.example.ini)和[AI接入计划](docs/frontend/AI-INTEGRATION-PLAN.md)填写本机配置。AI结果及图片在 `preview/local-data/ai-results/`，与任务备份分开。仓库克隆不会带回这些数据。

用户状态已升级到version2，兼容迁移v1任务与复盘；迁移前的磁盘原件为 `preview/local-data/user-state.before-v2.json`，浏览器旧记录另在本机backups归档。上一份备份同一分钟最多更新一次。输入停顿800毫秒才保存。代码退回v0.3不代表它能直接读取v2数据，恢复前应分别核对代码与数据版本。
