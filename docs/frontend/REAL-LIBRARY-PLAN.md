# v0.2 真实资料、本地更新与AI接入位置

2026-10-29。用户认可现有页面，授权本地继续完善，读取本机Codex/Claude、作品和知识入口。选择先实现无需APIKey的公开资讯更新，后续支持API与中转。未授权部署或外传私人资料。

## 已确定的实现

- 保留八个业务板块和现有UI，增加辅助“AI与连接”入口。
- 真实资料：项目、Skill、作品、素材、知识入口、思路与愿望。每条显示来源、观察时间与证据限制。优先复用既有全量索引，补查新增日志与真实文件；不能宣称逐句审阅全部历史。
- 展示本机私有资产的脱敏摘要和受控预览。源文件只读，原知识库不重构；不将完整聊天、客户资料、凭据复制到页面或发送外部。
- 应用代码与本地资料分开：local-data/、私人目录与媒体索引均不入Git；不在静态dist存放私人资料。代码历史不包含私人资料。
- 本地服务器支持只读资料接口、白名单文件预览、受控媒体Range、本地记录持久化/备份、固定官方公开源手动刷新。仅监听127.0.0.1，校验Host/Origin，不提供任意路径/URL代理。
- 资讯会显示来源日期、实际抓取时间、部分失败和旧缓存。获取公开来源时不附带私人项目背景；无定时自动化。
- AI与中转当前保存非敏感连接草稿及应用场景，不接受密钥、不试连收费接口。用户后续选定服务和权限后再接密钥、模型调用。搜索API与模型API分开理解，不能假设所有模型能联网。
- IP与选题：连接个人主张、受众问题、真实案例、作品与下一条内容；建议不冒充用户已批准决定，不强制增加发布频率。

## 文件边界与验证

- lib/library.cjs：汇总本地目录，按ID建立文件白名单，脱敏、校验、可恢复记录写入。
- lib/public-news.cjs：独立公开源刷新模块，失败保留旧记录，状态明确。
- dist/enrich.js + enrich.css：真实资产浏览、筛选/搜索、媒体与来源预览、资讯刷新、想法转任务、连接草稿。
- tools/build-library.cjs：本地资料汇总与快照生成，绝不上传。
- tests：先覆盖路径/来源/状态/密钥字段过滤和持久化，再实现；公开源测试由独立模块承担。
- 浏览器：真实项目详情、Skill/知识检索、视频/图片预览、想法来源与转任务、资讯刷新与失败状态、连接草稿、重启恢复、手机布局。

## 补充的设计判断

工作台承接“我要做什么、已有积累、外部机会、下一步行动”四类信息。保留证据等级与状态，避免堆成收藏夹。信息→我的判断→小实验→作品/知识/业务反馈→复盘，逐步连接，而非增加更多独立首页。

## 实际验收

已完成；20项测试及本机HTTP集成通过，浏览器核对来源、目录、媒体、搜索、保存、备份、刷新和手机布局。独立审查的恢复副本、跨端口资源和JSON脱敏问题已修正。私人元数据最终只经受控API读取，dist不加载私人快照。参见CURRENT-STATE.md与preview/evidence/verification-v02.json。
