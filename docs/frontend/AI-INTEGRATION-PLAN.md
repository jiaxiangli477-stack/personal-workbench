# 本地 AI 文字与生图接入

日期：2026-10-29。用户已明确要求按两家文档分别配置、实测文字与生图，然后接入工作台；主站需要 v1 时允许添加，覆盖旧 D017 的本轮试验限制。沿用当前页面，不再重复征求已有制作授权。

## 设计与边界

- 半成品个人工作台；唯一用户是本人。入口为“AI 与中转连接”，首个选择是文字或图片，然后手动提交一段输入，查看结果与线路。
- 保留当前原生 HTML/CSS、Node 本机服务、导航和资料主源。只做本页局部接入，不增加 SDK、第三方 UI 或后台任务。
- 比较：前端直连会暴露密钥；完整网关增加部署与维护。选择本机服务端适配器，读取 Git 忽略的私有填写文件，只返回非敏感状态和生成结果。
- 固定能力与模型：文字 deepseek-v4.1-flash；图片 gpt-image-2，请求1024x1024、每次一张。供应商基础地址来自本机配置，路径按供应商和能力分别选择，不双重追加v1。
- 已有证据：主站聊天 /v1/chat/completions；备用聊天 /chat/completions；两站图片 /v1/images/generations，其中备用已实际出图。主站图片密钥仍需实际核对。网页HTTP200不算模型成功。
- 原始密钥只在本机服务端内存和私有配置；不进入 GET 状态、前端、浏览器存储、普通日志、Git、错误提示和备份用户记录。浏览器不能提交目标URL/密钥/模型来扩权。
- 请求只发送手动输入；不自动附加项目、知识、客户或原始聊天。结果以文本转义展示，图片只通过受控本机文件ID读取，第三方图片URL不交给浏览器。
- 主用先尝试；文字明确失败可一次备用；生图仅在明确拒绝且没有生成任务/结果时一次备用。超时、断连、已返回图但下载失败不自动再次生成，提示可能已执行。
- UI显示加载、停用、错误、实际使用线路、是否备用以及真实图片尺寸。服务返回尺寸与请求不同，保留原件并明确提示，不篡改或宣称1K严格通过。
- 不安装、部署、推GitHub、修改Codex/Claude全局供应商或启用自动刷新。既有公开资讯更新和本机笔记保持独立。

## 前端检查点

保留：当前卡片、按钮、边距、字色和导航。调整深度：仅连接页。主任务：手动输入到可核对结果。恢复路径：清楚区分配置、鉴权、上游、超时和尺寸差异，允许用户修改私有表后重新加载状态。移动主操作在输入框旁，生成中禁用重复提交；不把供应商协议、密钥结构或内部诊断作为页面主文案。通过说明和次级详情交代费用、发送范围与线路。
