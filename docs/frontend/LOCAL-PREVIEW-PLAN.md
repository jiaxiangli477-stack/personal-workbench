# 本地工作台预览设计与实现计划

2026-10-29。用户已明确授权按现有八板块制作本地可打开、可点击页面；本次不部署。

## 设计

- 新建个人工作台预览，用户以首页判断今天做什么，再进入项目、内容或资讯详情。
- 首屏优先：今日约1小时的建议任务、项目阶段、对本人有用的资讯工具。
- 八个导航入口、各页用途说明和备注；任务、加入试用、备注和复盘提供浏览器本地保存。
- 白色侧栏、冷灰底、深蓝文字、克制蓝色重点，中文系统字体16px起；日程作为横向轻量提示，不制造虚构经营指标。
- 颜色：背景#f4f6fa，表面#ffffff，正文#18243b，次要文字#59677e，主色#355ce7，辅助绿#197568。
- 使用原生HTML/CSS/JavaScript，Lucide本地图标；没有安装包、后端、登录或外部模型调用。已有工具推荐使用上轮核对来源，标注未实测及核查日期。
- 注释采用每页说明、区块简短备注和详情中的用途说明，避免把开发文档放到主界面。
- 响应式：宽屏侧栏＋内容；窄屏可打开导航，任务优先；键盘可达、焦点可见、原生dialog和减少动效。
- 示例任务和制作阶段明确为布局体验，实际项目使用已知阶段，不把进度条当真实业务完成比例。

## 方案取舍

已检索Lucide与Shoelace开源项目并核对官方文档。采用Lucide静态SVG（ISC及部分MIT，保留LICENSE），原生控件已足够；不引入完整组件库与构建链。图标落地后不依赖CDN。无需生成位图按钮和背景。
